# Wild Switch 動物變身冒險

目前入口：`index.html`（或 `adventure.html`）。

操作：← → 移動、空白鍵跳躍收星、1–4 選動物、E 施展動作通過地形；P 暫停。手機提供觸控虛擬按鈕。
探索／聽力兩種模式，8 個基礎地形，錯誤項目延後再次出現，每項最多追加一次；下次優先練習不熟項目。使用 8 個英文動物名稱與 8 個動作發音音檔。
遊戲角色直接採用卡片動物圖片（去背透明化 Sprite），支援左右轉向與跳躍。

開啟 index.html 即可遊玩；或在此資料夾執行 `python -m http.server 8765 --bind 127.0.0.1`，瀏覽 http://127.0.0.1:8765。

來源：V1 第 04–09 頁。採用課本的 owl/fly、rabbit/hop、frog/jump、dog/run、eagle/soar、duck/walk、fish/swim、iguana/climb 配對；提示是依課本圖片／句型作答，不代表動物只有一種能力。

三種路線：看圖文字救援、聽單字救援、優先複習錯誤項目。每輪 8 個基礎任務；錯誤項目在最多三個其他任務後重現，每項最多追加一次，所以最多 16 站。每站先辨識動物，再選動作。完成與錯誤累計保存在 localStorage；無法使用儲存空間時仍可遊玩。

音訊使用資料夾現有 V1_<word>.mp3，未使用 JSON 中不存在的 UUID 音檔。聲音失敗有文字替代。兩隊合作在同一裝置交替操作，共同完成救援。

控制：點選卡片或按 1–4，Enter 下一步；Tab/Enter 可操作所有按鈕；F 全螢幕，Esc 離開。
